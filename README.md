# Quiz Interativo

 projeto em Python.

## Sobre o projeto

Este projeto é um quiz interativo desenvolvido em Python.
O programa apresenta perguntas ao usuário, verifica as respostas
e mostra a pontuação final.

## Funcionalidades

- Apresenta perguntas ao jogador
- Recebe respostas pelo teclado
- Verifica se a resposta está correta
- Conta os acertos
- Mostra a pontuação final

## Tecnologia utilizada

- Python 3

## Como executar

No terminal, dentro da pasta do projeto, execute:

python3 quiz.py

## Objetivo

Este projeto faz parte dos meus estudos de programação em Python,
com foco em lógica de programação, variáveis, entrada de dados,
condições e controle de fluxo.
